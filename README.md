# IPAK Organizational Structure

Static slide deck. Every page is fully self-contained (CSS, JS and images are embedded), so each file opens and previews on its own.

```
index.html         Home: title, Why we need evolved Structure, Evolved Structure Ideology
operations.html    Operations department
technical.html     Technical department
finance.html       Finance & Treasury department
```

Navigation: arrow keys, swipe, side arrows or the top tabs. Next/previous at the end/start of a page moves to the adjacent page (needs the files in the same folder).
