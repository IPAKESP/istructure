# IPAK Organizational Structure

Static slide deck, split by section. No build step; open `index.html` in a browser (or host the folder on GitHub Pages).

```
index.html         Home: title + "Why we need evolved Structure"
operations.html    Operations department
technical.html     Technical department
finance.html       Finance & Treasury department
assets/
  style.css        Shared styles
  deck.js          Shared slide navigation
  logo.png
  org-operations.png / org-technical.png / org-finance.png
```

Navigation: arrow keys, swipe, side arrows or the top tabs. Next/previous at the end/start of a page moves to the adjacent page.
